১) ZIP Extract করুন।
২) Android Studio > Open > JoyMartLLP_Android_Full_Project folder select করুন।
৩) JDK 17 এবং Android SDK Platform 35 install থাকতে হবে।

এই package-এ main.zip-এর সর্বশেষ source, compact Genealogy update এবং Wallet/Transactions screen একত্র করা হয়েছে। Laravel/server-এর কোনো file নেই; server পরিবর্তন হবে না।

নোট: মূল upload-এ gradle-wrapper.jar ছিল না। তাই gradlew scripts প্রথমবার official Gradle 8.9 download করে চালাবে; internet লাগবে। এখানে Android SDK না থাকায় APK build test করা সম্ভব হয়নি।
